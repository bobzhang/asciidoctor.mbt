= Arranged blocks
:icons: font

Blocks are arranged as asciidoctor-pdf's `arrange_block` does: a dry run tells whether the block would put nothing but its caption or background on the current page, in which case it starts on the next page.
The destination of a block with an id goes before its caption.

<<ex-first>>, <<code-first>>, <<side-first>> and <<quote-first>> are referenced here, with a footnote.footnote:[The footnote is counted once, whatever the dry runs convert.]

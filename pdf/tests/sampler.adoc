= PDF Backend Sampler
Jane Doe <jane@example.org>

This sampler exercises the features the PDF backend spike covers: headings, paragraphs with *bold*, _italic_, `monospace` and https://asciidoctor.org[links], lists, code blocks, tables and admonitions.

== Paragraphs and inline formatting

A paragraph set in the base font is justified across the full width of the page, and the last line of the paragraph is left ragged, which is what the default theme of Ruby asciidoctor-pdf does for body text.
It contains *strong text*, _emphasized text_, *_both at once_*, `monospaced code`, a superscript E=mc^2^, a subscript H~2~O, #highlighted text# and a link to https://github.com/asciidoctor/asciidoctor-pdf[the asciidoctor-pdf project].

A second paragraph refers back to <<_lists>> with an internal cross reference, and to a bare URL: https://example.org.
Typographic quotes such as "`double`" and '`single`' and the apostrophe in it's are replaced by curly quotes -- and double hyphens by an em dash.

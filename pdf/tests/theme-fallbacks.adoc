= Fallback Fonts
:pdf-theme: default-with-font-fallbacks

The default theme with font fallbacks sets characters its fonts lack in M+ 1p (and Noto Emoji): Japanese such as 日本語の文章 and ひらがな, and arrows such as → and ⇒ and ← in running text.
